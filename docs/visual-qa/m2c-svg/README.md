## Reproducible preparation and safety

`pnpm assets:prepare` verifies the ZIP manifest and SHA-256 values, parses/optimizes each SVG with pinned `svgo@4.0.0`, injects a geometry-preserving `viewBox` where absent, and writes deterministic external production copies and `apps/web/public/assets/asset-manifest.json`. `pnpm assets:check` repeats preparation and compares every generated byte. The validator rejects DTD/entity declarations, script/foreign content, event handlers, CSS imports/expressions, and non-fragment references/URLs. Optimized output is checked again. The source ZIP remains outside `apps/web/public`.

No remote asset URLs, inline SVG injection, React SVG path trees, animation package, or runtime asset service is used. CSS transforms and bounded effects decorate the source images without implying independent limb motion.

## Implementation and authority

`AnimatedBoss` is shared by the dashboard and overlay. It maps only the strict body, element, special, and weakness vocabularies. Before a validated forge reveal, it renders a neutral forging mark rather than a guessed boss. Reveal, accepted-hit, weakness-hit, low-health, victory, expiry, cancellation, and unavailable treatments are driven by existing authoritative presentation state. Hit feedback requires an accepted-hit count change within the same current identity; mount/reconnect does not replay old hit counts. Reduced motion disables the state-triggered animation classes. No gameplay rules, backend state, Phaser code, or OBS controls changed.
