# BossForge Live

Chat creates the boss. The streamer fights it.

BossForge Live is an interactive browser game concept for Twitch streams. This
repository is being built from the ground up for the Codex x TwitchCon 2026
hackathon. The initial bootstrap establishes the repository; implementation is
underway on the Phase 0 feature branch.

See the Phase 0 implementation and development instructions on
`feat/phase0-foundation`.
